# DiagnoVet IA — Landing Page

Landing page institucional do **DiagnoVet IA**, plataforma de interpretação de exames laboratoriais veterinários com inteligência artificial.

## 🚀 Como publicar (GitHub Pages)

1. Crie um novo repositório no GitHub (ex: `diagnovet-landing`)
2. Faça upload de **todos os arquivos desta pasta** (incluindo `index.html`)
3. Vá em **Settings** → **Pages**
4. Em **Source**, selecione:
   - Branch: `main`
   - Folder: `/ (root)`
5. Clique em **Save**

Em ~1 minuto, o site estará no ar em:
`https://<seu-usuario>.github.io/<nome-do-repo>/`

## 📦 Conteúdo

- `index.html` — Página única, autocontida (todos os assets, fontes e estilos embutidos). Funciona offline.
- `README.md` — Este arquivo.

## 🎨 Personalização

O arquivo `index.html` é uma versão "compilada" — toda a fonte, CSS e SVGs estão embutidos. Para editar texto ou cores diretamente, abra-o em um editor e busque pelo conteúdo que deseja alterar.
